# Annotated Bibliography (APA 7th Edition)

All entries below were independently opened via `WebFetch` against the listed URL
during this research pass (2026-09-14) to confirm the source is real and to extract
the author list and date; none are cited from a search-result snippet alone. Where a
paper has both an arXiv preprint and a peer-reviewed venue, the venue is noted after
the reference; the URL given is the one actually fetched.

---

**Arazo, E., Ortego, D., Albert, P., O'Connor, N. E., & McGuinness, K. (2020). Pseudo-labeling and confirmation bias in deep semi-supervised learning.** arXiv. https://arxiv.org/abs/1908.02983 *(published at IJCNN 2020)*

Shows that naive pseudo-labeling in semi-supervised learning induces "confirmation
bias": a model trained on its own noisy pseudo-labels becomes progressively more
confident in its own mistakes, and mitigations (mixup, minimum-labeled-per-batch)
are needed to prevent the errors from compounding. This is the closest general-ML
analogue to this project's "correction cascade" mechanism (`sam2-sav-failure-analysis.md`,
"No-oracle drift-detection policy" section; `sam2-drift-recovery-results.md` §5): a
self-referential correction signal — the model's own last-trusted mask — degrades
because the reference used to detect and correct drift is generated by the same
process that produces the errors it is meant to fix. The project's finding that
self-mask reference (F1, single-mask) and consensus-of-own-masks reference (F2) both
plateau far below the oracle ceiling (`J&F∈[23.8,27.4]` vs. oracle `84.3`,
`sam2-drift-recovery-results.md` §5) is a video-segmentation instance of exactly the
confirmation-bias dynamic this paper formalizes for classification.

---

**Cheng, H. K., Oh, S. W., Price, B., Lee, J.-Y., & Schwing, A. (2023). Putting the object back into video object segmentation.** arXiv. https://arxiv.org/abs/2310.12982

Introduces Cutie, which replaces bottom-up pixel-level memory matching (used by STM
and XMem) with top-down object-level memory reading via learned object queries,
specifically to reduce matching noise from **distractors** — objects visually similar
to the target. Cutie's premise (pixel-level matching alone is not distractor-robust)
is directly relevant to this project's diagnosis that its own area-ratio/position-jump
trigger cannot distinguish "identity switch onto a visually identical distractor" from
"legitimate fast motion or scale change" (`sam2-drift-recovery-next-directions.md` §1).
Cutie represents an architectural (trained) route to distractor robustness that this
project's frozen-SAM2, prompt/re-prompt-only approach does not have access to by design.

---

**Cheng, H. K., Oh, S. W., Price, B., Schwing, A., & Lee, J.-Y. (2023). Tracking anything with decoupled video segmentation.** arXiv. https://arxiv.org/abs/2309.03903 *(ICCV 2023)*

Presents DEVA, which decouples task-specific image segmentation from a reusable
temporal-propagation module and uses **bi-directional propagation** — fusing
segmentation hypotheses from multiple frames rather than committing to a single
forward-only chain — to build a coherent track. This is architecturally close to what
this project's un-implemented alternatives (D3 sliding-window correction rate,
consensus-of-K reference masks — `sam2-sav-failure-analysis.md`, "Кандидат #3:
консенсус") gesture toward, but DEVA achieves it through a trained bi-directional
fusion model rather than a heuristic on a frozen video predictor, which is the
structural reason it can resolve ambiguity that a single-direction, single-reference
no-oracle heuristic (as used throughout this project) cannot.

---

**Cheng, H. K., & Schwing, A. G. (2022). XMem: Long-term video object segmentation with an Atkinson-Shiffrin memory model.** arXiv. https://arxiv.org/abs/2207.07115 *(ECCV 2022)*

Introduces a three-tier memory architecture (sensory / working / long-term) with a
consolidation mechanism explicitly designed so that long videos do not force the model
onto a small, aging set of anchor frames. This is the direct architectural counterpart
to the mechanism this project traces for SAM2's own failure: SAM2's fixed memory
buffer eventually rolls over so that only the original prompt frame anchors long
propagation, after which the model can drift onto a distractor (see also Ding et al.,
2024, below, and search-verified analyses of SAM2's memory buffer behavior). XMem's
long-term memory is a trained, architectural solution to a problem this project
addresses only heuristically and post hoc, at inference time, on a frozen checkpoint.

---

**Ding, S., Qian, R., Dong, X., Zhang, P., Zang, Y., Cao, Y., Guo, Y., Lin, D., & Wang, J. (2024). SAM2Long: Enhancing SAM 2 for long video segmentation with a training-free memory tree.** arXiv. https://arxiv.org/abs/2410.16268 *(ICCV 2025)*

Diagnoses, for SAM2 specifically, the same "error accumulation" pattern this project's
capstone run exposes: an erroneous or low-quality mask written into SAM2's memory
propagates forward and degrades subsequent frames, and on long videos the fixed memory
buffer eventually loses the anchor frame, allowing drift onto a similar-looking
distractor. SAM2Long's fix is training-free but operates *within* the propagation loop
(maintaining multiple candidate segmentation pathways per frame and pruning by
cumulative score, i.e., an internal, continuous hedge against a bad single-path
commitment) rather than as an external, binary drift-detect-then-reprompt intervention
like this project's P5. It reports gains that grow with video length and are near-zero
on short videos (DAVIS), which is a useful external confirmation that a frozen-SAM2
memory-drift problem is real and length-dependent, independent of this project's own
diagnosis (`sam2-drift-recovery-results.md` §3, propagation-drift = 83% of SA-V
failures). SAM2Long was not tried by this project and is a genuine, untested candidate
for the diagnosed bottleneck — see `synthesis.md`, Candidate Future Work.

---

**Huang, J., Chen, X., Mishra, S., Zheng, H. S., Yu, A. W., Song, X., & Zhou, D. (2023). Large language models cannot self-correct reasoning yet.** arXiv. https://arxiv.org/abs/2310.01798 *(ICLR 2024)*

Shows that LLMs prompted to critique and revise their own reasoning, without external
verification signal, frequently make correct answers worse, not better — self-correction
requires an external, reliable oracle to be net-positive. This is a cross-domain
(language, not vision) but mechanistically close analogue to this project's finding
that P5's self-triggered corrections, when applied without an external
(ground-truth-derived) filter on *which* objects need correction, are net-harmful on
the full SA-V-val population (`sam2-drift-recovery-results.md`, capstone section:
`J&F` 72.1→68.7). Both findings point to the same structural requirement: a
self-correcting system's net benefit depends on the reliability of its own trigger for
"correction needed," not on the quality of the correction once triggered.

**Kirillov, A., Mintun, E., Ravi, N., Mao, H., Rolland, C., Gustafson, L., Xiao, T., Whitehead, S., Berg, A. C., Lo, W.-Y., Dollár, P., & Girshick, R. (2023). Segment Anything.** arXiv. https://arxiv.org/abs/2304.02643 *(ICCV 2023)*

The original Segment Anything (SAM) paper: a promptable image segmentation
foundation model trained on the 1.1-billion-mask SA-1B dataset, establishing the
point/box-prompt-to-mask paradigm this project's `box_centroid` and
`largest_component_box_centroid` prompt policies build on directly
(`sam2-full-validation-report.md`; `sam2-drift-recovery-results.md` §2). SAM2 (Ravi et
al., 2024, below) extends this model family to video; this project operates entirely
within the SAM/SAM2 promptable-segmentation paradigm rather than training a new model.

---

**Meta AI. (2024). SA-V dataset.** https://ai.meta.com/datasets/segment-anything-video/

The official project page for the SA-V (Segment Anything Video) dataset — 50.9K
videos and roughly 643K spatio-temporal masklets, introduced alongside SAM2 (Ravi et
al., 2024) — confirming the dataset's scale and stated challenge profile (small,
frequently-occluded, reappearing objects). This project's entire evaluation surface
(`sav_val`: 155 videos / 293 objects; `sav_test`: 150 videos / ~278 objects) is drawn
from this dataset's official val/test splits (`sam2-full-validation-report.md`,
"SA-V validation status"). The page's stated challenge profile (occlusion,
reappearance, small objects) is consistent with, and gives independent grounding for,
this project's own empirical decomposition of SA-V failure into prompt-frame collapse
and propagation-drift (`sam2-sav-failure-analysis.md`).

---

**Oh, S. W., Lee, J.-Y., Xu, N., & Kim, S. J. (2019). Video object segmentation using space-time memory networks.** arXiv. https://arxiv.org/abs/1904.00607 *(ICCV 2019)*

Introduces Space-Time Memory (STM) networks, the foundational memory-matching
architecture for semi-supervised VOS that XMem, Cutie, and (in spirit) SAM2's own
memory attention mechanism descend from: past frames with known masks form an
external memory that the current frame is matched against densely in feature space.
Establishes the memory-matching paradigm whose long-horizon failure mode (matching
noise compounding against distractors) motivated the later, architecturally distinct
fixes (XMem's tiered memory, Cutie's object-level queries) that this project's
prompt/re-prompt-only, frozen-model approach cannot draw on.

**Ravi, N., Gabeur, V., Hu, Y.-T., Hu, R., Ryali, C., Ma, T., Khedr, H., Rädle, R., Rolland, C., Gustafson, L., Mintun, E., Pan, J., Alwala, K. V., Carion, N., Wu, C.-Y., Girshick, R., Dollár, P., & Feichtenhofer, C. (2024). SAM 2: Segment Anything in Images and Videos.** arXiv. https://arxiv.org/abs/2408.00714

The SAM2 paper: extends SAM to video via a streaming memory-attention mechanism and
introduces the SA-V dataset. This is the model and checkpoint family this entire
project evaluates (SAM2.1 Hiera-Tiny, frozen — `sam2-iteration-log.md` iterations
0a-0c). The paper reports SAM2 needing "3x fewer interactions" than prior interactive
VOS approaches, which frames this project's central object of study (a *prompt and
re-prompt policy* for a frozen SAM2, rather than a fine-tuning or architectural
change) as operating exactly in the design space SAM2's own authors position as SAM2's
efficiency lever — this project stress-tests that lever's limits on a harder,
independent benchmark split than SAM2's own reported numbers.

**Saito, T., & Rehmsmeier, M. (2015). The precision-recall plot is more informative than the ROC plot when evaluating binary classifiers on imbalanced datasets.** *PLOS ONE, 10*(3), e0118432. https://doi.org/10.1371/journal.pone.0118432

Demonstrates formally that under class imbalance, a classifier's apparently strong
per-instance performance (which ROC-style metrics can make look good) does not
guarantee useful net precision, because false positives on the large majority class
overwhelm true positives on the rare minority class — precision, not recall or
per-class accuracy, is what collapses. This is the closest general statistical
grounding, found in this search pass, for the single most important quantitative
pattern in this project: with only ~10% of SA-V-val objects genuinely needing drift
correction (`sam2-drift-recovery-next-directions.md` §2), the capstone run's implied
trigger false-positive rate on the healthy 90% (~68% per §2) numerically explains why
178/293 objects regressed against only 44 improvements
(`sam2-drift-recovery-results.md`, capstone section) despite P5 achieving up to +90pp
J&F on individual true positives. This project's own framing ("специфічність
тригера... а не точність корекції" — trigger specificity, not correction precision, is
the bottleneck; `next-directions.md` §1) is a direct, independently-arrived-at
restatement of the precision-under-imbalance problem this paper formalizes.

**Videnovic, J., Lukezic, A., & Kristan, M. (2024). A distractor-aware memory for visual object tracking with SAM2.** arXiv. https://arxiv.org/abs/2411.17576 *(CVPR 2025)*

Introduces DAM4SAM: a drop-in distractor-aware memory module and an
introspection-based memory-update strategy for SAM2, built specifically because
plain SAM2 memory can be corrupted by confident but wrong drift onto a distractor —
the same failure this project traces mechanistically in its `sav_017171` and
`sav_004755` test-set catastrophes (fresh-box-reprompt confidently re-anchoring on the
wrong target after one bad trigger; `sam2-drift-recovery-results.md`, "Закриття
відкритих питань P5"). DAM4SAM's introspection mechanism — deciding *whether to trust
and write* a given frame's mask into memory before committing to it — is architecturally
adjacent to, but distinct from, this project's B1 (post-hoc plausibility check on the
correction's output) and A2 (rate circuit-breaker); DAM4SAM was not tried by this
project and is flagged as untested future work in `synthesis.md`.

---

**Wang, D., Shelhamer, E., Liu, S., Olshausen, B., & Darrell, T. (2020). Tent: Fully test-time adaptation by entropy minimization.** arXiv. https://arxiv.org/abs/2006.10726 *(ICLR 2021)*

A canonical test-time-adaptation (TTA) method: a frozen model is adapted online at
inference time using only its own predictions (entropy minimization over normalization
statistics), with no ground truth and no source data — the same "frozen model,
self-supervised correction signal, no oracle" setting this project operates in
throughout (`sam2-drift-recovery-charter.md` §1: "no-oracle... method"). Tent
represents the canonical, successful end of the TTA spectrum; this project's P5 and
its eleven mitigation variants are, structurally, a bespoke, non-gradient-based TTA
mechanism for a video segmentation model, and the broader TTA literature's central
open question — when does self-supervised test-time correction generalize vs.
compound its own errors — is exactly the question this project's val-to-test
generalization gaps (P5: +15.5pp val → +2.0pp test; P2: +0.4pp val → -0.3pp test,
`sam2-drift-recovery-results.md` §"P5 на held-out sav_test", "Ізольований P2") answer
empirically for one specific mechanism.

---

**Wang, Q., Fink, O., Van Gool, L., & Dai, D. (2022). Continual test-time domain adaptation.** arXiv. https://arxiv.org/abs/2203.13591 *(CVPR 2022)*

Identifies that in long-horizon test-time adaptation, pseudo-labels become
unreliable over time and self-training on them causes both catastrophic forgetting and
**error accumulation** — and proposes weight-averaged/augmentation-averaged
predictions plus stochastic parameter restoration specifically to blunt this. The
paper's core diagnosis (naive self-supervised correction accumulates error over a long
sequence unless deliberately dampened) is the general-TTA-literature counterpart to
this project's own, independently observed "correction cascade" mechanism
(`sam2-sav-failure-analysis.md`: objects with >15 self-corrections regress by a mean
-10.6pp, vs. +20.6pp for objects with ≤15) and to the eventual finding that
object-level rate limiting (A2) — a circuit breaker, conceptually close to CoTTA's
stochastic restoration — was this project's single most effective (though still
net-negative) mitigation (`sam2-drift-recovery-next-directions.md` §5, step 4).

---

**Voigtlaender, P., Luiten, J., Torr, P. H. S., & Leibe, B. (2020). Siam R-CNN: Visual tracking by re-detection.** arXiv. https://arxiv.org/abs/1911.12836 *(CVPR 2020)*

A classical (pre-SAM) long-term visual tracker built around global re-detection and a
Tracklet Dynamic Programming Algorithm that explicitly tracks distractor objects
alongside the target to resolve which detection is the "real" one over time, rather
than committing greedily to the nearest or most-confident match on each frame. This is
a directly relevant precedent for this project's found bottleneck: SAM2's own
per-frame multimask selection already performs an internal, greedy confidence-based
choice among 3 candidate masks (confirmed inert in this project's P1 diagnostic —
`sam2-drift-recovery-results.md` §8b, `continuity_better=360` vs. `model_better=347`,
statistically a coin flip), and Siam R-CNN's design suggests that resolving distractor
ambiguity may require tracking multiple hypotheses *forward through time* rather than
re-deciding at each frame independently — a strategy this project's P5 (single
best-effort reprompt per trigger) does not implement.

---

**Zhu, Z., Wang, Q., Li, B., Wu, W., Yan, J., & Hu, W. (2018). Distractor-aware Siamese networks for visual object tracking.** arXiv. https://arxiv.org/abs/1808.06048 *(ECCV 2018)*

Introduces DaSiamRPN, which explicitly names and targets the "semantic distractor"
failure mode in Siamese trackers — visually similar objects that a similarity-only
signal cannot discriminate from the true target — via a distractor-aware training
objective and template update over time. This is the earliest, most direct precedent
for the specific failure this project's P5 was designed to fix: multi-instance
identity switches where appearance alone cannot disambiguate (e.g., `sav_022396`, ~15
visually identical balloons; `sav_035221`, two visually identical shoe soles —
`sam2-drift-recovery-results.md` §10, P5 section). DaSiamRPN's answer is a
*learned, appearance-based* distractor discriminator; this project's P5 answer is a
purely *positional* (motion-extrapolation) discriminator, chosen specifically because
appearance cannot separate visually identical instances — the two approaches are
complementary, not competing, and combining them is flagged as untested future work in
`synthesis.md`.
