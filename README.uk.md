# Відновлення після дрейфу на SA-V: дослідження негативних результатів

Емпіричне дослідження стратегій корекції дрейфу без оракула для **замороженої**
моделі сегментації відео SAM2.1 (Hiera-Tiny), оціненої на офіційному
[бенчмарку SA-V](https://ai.meta.com/datasets/segment-anything-video/). Жодні ваги
моделі в цьому проєкті ніде не донавчаються — кожне втручання тут є зміною
політики на рівні промпту чи інференсу.

**Головний результат:** механізм корекції дрейфу на основі моделі руху (свіжий
повторний промпт-бокс за екстраполяцією позиції з припущенням постійної
швидкості) відновлює великий приріст на попередньо відібраній за істинною
розміткою підмножині справді дрейфуючих об'єктів (+15.5 J&F на відомій
дрейфуючій підмножині), але є *чистою шкодою*, коли застосовується до повної,
невідібраної множини val SA-V (72.1 → 68.7 J&F). Вузьке місце — не точність
корекції, а **специфічність тригера**: частка хибних спрацювань на здорових
об'єктах, які взагалі не потребували корекції. Одинадцять подальших спроб
пом'якшення (гейтинг на рівні кадру, запобіжники на рівні об'єкта, попередній
відбір на основі ознак та пом'якшення корекції) так і не усунули цей розрив до
простої нескорегованої базової лінії. Найкращий результат усієї серії
залишається на 0.8–2.2 процентних пункти нижче за просту відсутність корекції.

Цей репозиторій містить код оцінювання, сирі результати на рівні об'єктів та
повний експериментальний наратив, що стоїть за цим висновком. Див.
[`paper/`](paper/) для чернетки статті та огляду літератури, побудованих на
основі цієї роботи.

**Стаття (English / Українська):** [`paper/paper.pdf`](paper/paper.pdf) ·

## Структура репозиторію

```
scripts/     Скрипти оцінювання та аналізу (власний код цього проєкту)
results/     Таблиці J&F-показників на рівні об'єктів (CSV) для кожного варіанту експерименту
paper/       Чернетка статті + огляд літератури (див. paper/research/)
sam2-*.md    Експериментальний журнал, методологія та звіти про знахідки (хронологічно)
```

Повні предиктовані маски по кадрах (>1M файлів, кілька ГБ) не відстежуються в
цьому репозиторії — лише агреговані/пооб'єктні таблиці показників, отримані
офіційним оцінювачем SA-V. Повторний запуск будь-якого скрипта нижче
регенерує їх локально.

## Налаштування

1. **Клонуйте SAM2 окремо** (Apache 2.0, Meta AI) — це залежність, не
   включена в цей репозиторій:
   ```
   git clone https://github.com/facebookresearch/sam2.git
   cd sam2 && pip install -e .
   # завантажте чекпоінти за власними інструкціями sam2, напр.:
   # sam2/checkpoints/download_ckpts.sh
   ```
2. **Встановіть власні залежності проєкту:**
   ```
   pip install -r requirements.txt
   ```
3. **Отримайте датасет SA-V** від Meta AI (потрібна реєстрація; SA-V має власні
   умови ліцензії, не покриті ліцензією цього репозиторію) і розмістіть/
   символьно прив'яжіть його так, щоб дефолтний `--sav-root` скриптів
   (`data/sav/sav_val`) вирішувався, або передавайте `--sav-root` явно.

## Запуск оцінювання

Кожен скрипт нижче оцінюється проти **офіційного** `sav_evaluator.py`
(постачається з репозиторію SAM2, `sam2/sav_dataset/sav_evaluator.py`) —
жодне з чисел J&F цього проєкту не походить з власної реалізації метрики.

```
python scripts/sav_full_pipeline_eval.py \
  --prediction-root results/my_run_pred \
  --soft-nudge-weight 0.0   # або будь-який з прапорців, задокументованих нижче

python sam2/sav_dataset/sav_evaluator.py \
  --gt_root data/sav/sav_val/Annotations_6fps \
  --pred_root results/my_run_pred
```

Ключові скрипти:

| Скрипт | Що робить |
|---|---|
| `sav_sam2_eval.py` | Базові політики промптингу (`box_centroid`, `largest_component_box_centroid`), без корекції дрейфу |
| `sav_motion_prior_reprompt_eval.py` | Основний механізм корекції дрейфу та всі прапорці пом'якшення (A1/B1/A2/D1-D4/F1 — див. docstring і `--help`), обмежений куратованою підмножиною об'єктів для швидких тюнінгових пілотів |
| `sav_full_pipeline_eval.py` | Той самий механізм, повний невідібраний SA-V val/test (155/150 відео) — саме тут проявляється справжня ціна хибних спрацювань |
| `sav_dryrun_risk_eval.py` | E1: некоригований пробний прохід, що збирає пооб'єктні ознаки ризику для експериментів з попереднім відбором |
| `sam2_multimask_capture.py` | Monkey-patch `track_step` SAM2: перехоплює відкинуті multi-mask кандидати, які модель рахує, але ніколи не зберігає |
| `sav_dryrun_multimask_risk_eval.py` | Некоригований пробний прохід, що видобуває ознаки multi-mask divergence (§13-продовження попереднього відбору E1) |
| `sav_risk_feature_correlate.py` | Перевикористовуваний ретроспективний кореляційний/decision-gate скрипт для risk-ознак проти capstone-delta (використаний E1 і multi-mask-перевіркою) |
| `sam2_memory_gate.py` | Monkey-patch `propagate_in_video`: пропускає запис у пам'ять на suspected-distractor кадрах (dynamic memory-gating, Phase A) |
| `sav_memory_gate_eval.py` | n=30-пілот threshold sweep для memory-gating на куратованій known-drift підмножині |
| `sav_memory_gate_full_eval.py` | Повне оцінювання memory-gating на SA-V val (293 об'єкти), за структурою `sav_full_pipeline_eval.py` |
| `sav_failure_mode_analysis.py` | Визначає, які об'єкти є справжніми відмовами через дрейф (використовується для побудови куратованої підмножини вище) |
| `davis_sam2_eval.py` | Базова валідація на DAVIS (перевірка налаштування SAM2 перед переходом до SA-V) |

Кожен прапорець пом'якшення, доданий протягом цього проєкту
(`--require-both-triggers`, `--plausibility-ratio`, `--max-correction-rate`,
`--correction-window`, `--early-trigger-skip-frac`, `--rate-warmup-corrections`,
`--soft-nudge-weight`), за замовчуванням `0`/вимкнено й точно відтворює просту
базову лінію, якщо не встановлений — див. текст `--help` кожного прапорця для
конкретного експерименту й датованого результату, якому він відповідає.

## Підсумок результатів

| Конфігурація | SA-V val J&F | SA-V test J&F |
|---|---:|---:|
| Базова лінія `box_centroid` (без корекції) | 72.1 | 74.4 |
| Capstone: корекція дрейфу, без відбору (OR-гейт) | 68.7 | — |
| A1 (AND-гейт тригера) | 69.0 | — |
| B1 (перевірка правдоподібності результату) | 68.2 | — |
| A2 (запобіжник частоти корекції на рівні об'єкта) | 71.1 | 72.2 |
| **D4 (A2 + A1 разом, найкращий результат серії)** | **71.3** | **72.6** |
| E1 (попередній відбір, усі 3 варіанти ознак) | немає прогнозувального сигналу (R² ≤ 0.044) | — |
| F1 (пом'якшене змішування корекції) | 67.9 | — |

Повні числа по кожному експерименту, механізми та датовані звіти — у
[`sam2-drift-recovery-next-directions.md`](sam2-drift-recovery-next-directions.md)
(основний експериментальний наратив, §1-14 — §13-14 охоплюють два
пізніших, окремо мотивованих follow-up дослідження поза цією серією:

memory-gating, пілот-позитивний, але негативний на full-val) та
[`sam2-drift-recovery-results.md`](sam2-drift-recovery-results.md) (сирий
журнал ітерацій).
